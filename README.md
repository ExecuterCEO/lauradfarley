# Laura D. Farley — Real Estate

Lead-generation site for **lauradfarley.com**

- Broker Associate · REALTOR® · eXp Realty
- DRE# 01723945
- Markets: Temecula → Orange County

## Stack

- Astro + Tailwind
- Netlify (hosting + forms)
- Static export

## Develop

```bash
npm install
npm run dev
npm run build
```

## Forms

Netlify Forms on:
- `home-lead`
- `home-valuation`
- `buyer-consult`
- `contact`
- `area-*`

Notifications should go to `laura.farley@exprealty.com` (configure in Netlify UI after first deploy).
